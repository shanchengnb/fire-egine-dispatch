## Data Availability Statement

The materials required to reproduce the analyses in this study are available in part as public resources; other materials are restricted because they contain confidential data supplied by the West Midlands Fire Service (WMFS).

### Publicly available materials (accessible via the two public OneDrive links supplied with this submission):

Final analytical and visualization datasets derived from the original data (subset suitable for public release).

Processed evaluation outputs (folder: eval_output).

Trained reinforcement-learning models (folder: models) and TensorBoard logs (folder: tensorboard).

Training and evaluation code, including the notebook used for analysis/evaluation (EVALUATE MODEL.ipynb).

Simulation / environment code (folder: env/).

Supporting partial datasets and auxiliary files used in analyses (examples: drv_time_osrm_renamed, station mapping/xy.pkl).

Additional project artifacts (folders named TRAIN MODEL, EVALUATE MODEL, etc.) that are included in the public OneDrive deposits.

### Restricted / not publicly shared (requires permission from the data provider):

Original training dataset: real_with_dispatch_info (WMFS proprietary).

Evaluation dataset: wmfs_mobilisations (WMFS proprietary).

Station_engine_counts.csv (not included).

station_dists.pkl — this file is visible in the OneDrive location but is extremely large and is treated as restricted in the original data sharing agreement.

These restricted datasets were supplied to the project by the West Midlands Fire Service and cannot be redistributed publicly under the data provider’s terms.

### Private repository:

A private GitHub repository contains the complete research package (original datasets, processed data, full codebase, and trained models). Access to that repository is currently restricted to the project supervisor, collaborators, and the author.

### How to request access for reproduction or further work:

Researchers who require access to the restricted WMFS datasets or to the private GitHub repository may contact the corresponding parties to request access. Requests will be considered on a case-by-case basis and any approved access will be provided under the WMFS data-sharing agreements and any applicable ethical and legal restrictions.

### Ethics and confidentiality:

The original WMFS datasets were provided under a data sharing arrangement and have been handled in accordance with the terms set by the data provider. The supervisor (Dr. Huanfa Chen) has confirmed that use of the data for the purposes of this research presents no ethical risk under the agreed terms. Any secondary access will require adherence to the same ethical, contractual, and confidentiality requirements imposed by WMFS.

### Reproducibility notes:

All files necessary to reproduce evaluation analyses (including processed datasets in eval_output, the evaluation notebook EVALUATE MODEL.ipynb, TensorBoard logs, and the trained models) are included in the public deposits. These materials are sufficient to reproduce the evaluation and analysis reported in the manuscript.

Reproducing model training exactly requires the proprietary original training dataset (real_with_dispatch_info) and the evaluation dataset (wmfs_mobilisations); to reproduce training, please contact the supervisor or the author to request access.

### Citation / use:

If you use the publicly available materials from the OneDrive deposits or any code or models released with this work, please cite this paper (or contact the authors for citation guidance) and respect the terms of use described in any accompanying README and license files.
